# C-Drive

**A Ride-Hailing Application**

## About the Project

C-Drive is a ride-hailing application developed to support digital transport services by connecting passengers and drivers through an online platform.

The project demonstrates practical application development, including user-facing functionality, backend integration and application workflows.

## Key Features

- Ride-hailing application functionality.
- Digital user experience for transport services.
- Backend-powered application workflows.
- Payment gateway integration (final integration pending).

## Technology Stack
